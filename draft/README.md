# Bounce Back draft

A playable sketch of the MVP in [STORY.md](../STORY.md). Colored rectangles, no art, no audio. **HC — Hack Club Haven.**

This folder is not the jam submission. The coder plays it, then rebuilds the loop in the root project with the crew's own sprites and music.

## Run

1. Install Godot 4.7.
2. Import this folder's `project.godot` (the one inside `draft/`, not the root project).
3. Press F5.

Move with WASD or the arrow keys. Space talks, hits the bar, and mashes you back up.

House, then the exam, then three papers, then the picture, then the roof. The phone says he passed.
